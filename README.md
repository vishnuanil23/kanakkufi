# KanakkuFi 💰

KanakkuFi is a scalable expense tracking application built using Flutter and Supabase.

Initially focused on pregnancy-related expenses, but architected for future expansion into a full personal finance platform.

---

## 🚀 Tech Stack

- Flutter (Mobile + Web)
- Supabase (Auth + PostgreSQL)
- Clean Architecture
- MVVM Pattern
- Riverpod (State Management)

---

## 🏗 Architecture

Presentation → Domain → Data → Supabase

---

## 🌳 Branching Strategy

- main → production
- dev → development
- feature/* → feature branches
